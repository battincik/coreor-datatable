# Contributing

Thank you for improving Coreor DataTable. Open an issue for significant API changes before implementation. For a change, keep the library and showcase examples in sync, run `npm test`, `npm run lint` and `npm run build`, and describe the behavior and tests in your pull request.

Library code lives in `src/components/` and `src/lib/`. Run `npm run build:lib` to regenerate the publishable package. No npm credentials are needed for local development. Please do not include private data, API keys or generated `node_modules` in commits.
